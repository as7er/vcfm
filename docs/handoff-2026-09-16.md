## 2. 下一台设备最该先做的一件事（**上一轮做到一半**）

- ⚠ **但那个读数是在「从 1440×1000 缩到手机尺寸」之后量的**，所以**可能是 resize 产物**，
  也可能真实存在。**没验证过之前不要写进结论、也不要直接改 CSS。**
- 验证方法（几分钟）：让页面**直接以 390×844 启动**（不是 resize），走到开赛前状态，
  量 `#match-pre-brief` 的 `clientHeight` 与 `scrollHeight`。
  探针现在固定 `newPage({ viewport: 1440×1000 })`（`:231`），需要加一个「初始视口」开关。
- 若复现，成因已定位（只需验证，不必重查）：`.match-pre-brief` 是
  `flex: 0 1 auto; min-height: 0`（`css/style.css:6802-6804`），而开赛前
  `.fmm-match-body` 被设成 `flex: 0 0 auto`（`:6823`）——**唯一可收缩的子项吸收了全部挤压**。

  它自己按 `max-height: min(36vh, 300px)` 内滚。⚠ 宽屏（≥1060px）是 grid 布局，
  flex 属性对 grid item 无效，所以这个改法对桌面无副作用——但仍要复测。

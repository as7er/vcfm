## 读这些文件的纪律

1. **12 场不能看进球。** 12 场进球标准误约 ±0.35；同一批引擎的四组 12 场读数
   分别是 2.50 / 2.50 / 3.50 / 2.25（抖动 1.25 球）。
2. **跨版本不能相减**，除非两边都是**实跑**出来的（见上表「提交」列）。
   文档表格里没有「引擎提交」列的数字，只能当方向性预期。
3. 每份输出开头的 `[0] 包装自检` 必须显示「✅ 一致」——
   否则 control 档有侧效应，全表作废。
